Log File Structure

A log file is a sequence of YAML documents separated by ---. Each document is one event. The events relevant to LLM modifications are those with the lifecycle transition description/exposition.

--- # Event document: one LLM modification step
cpee:lifecycle:transition: description/exposition
cpee:change_uuid:          3f8a2b1c-94e6-4d12-b901-7f3c5a8d2e44
time:timestamp:            2024-11-03T14:27:53.482Z
cpee:exposition: |
  <!-- Input CPEE-Tree -->
  <description>
    <call id="1" label="Fetch Order">...</call>
    <call id="2" label="Process Payment">...</call>
  </description>

  %% Input Intermediate
  flowchart TD
    1["Fetch Order"]
    2["Process Payment"]
    1 --> 2

  # User Input:
  Add an approval step between Fetch Order and Process Payment.

  %% Output Intermediate
  flowchart TD
    1["Fetch Order"]
    3["Approval Check"]
    2["Process Payment"]
    1 --> 3 --> 2

  <!-- Output CPEE-Tree -->
  <description>
    <call id="1" label="Fetch Order">...</call>
    <call id="3" label="Approval Check">...</call>
    <call id="2" label="Process Payment">...</call>
  </description>

  # Used LLM: gpt-4o
