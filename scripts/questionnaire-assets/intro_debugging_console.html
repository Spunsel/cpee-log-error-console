CPEE LLM Debugging Console

You will now use the CPEE LLM Debugging Console — a tool for inspecting LLM-driven process modifications step by step.

To get started, click the tour icon in the top-right corner of the console to start the interactive walkthrough. It will guide you through all relevant features and show you how to identify the three types of errors.

What the tour covers

Navigation between modification steps, how to switch views, and how to spot syntax, conversion, and structural errors — all shown on a real instance.

Duration & interaction

The tour is interactive — you will perform actions in the console as part of it. You can exit at any time and resume the questionnaire.
